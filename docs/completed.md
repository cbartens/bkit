Added KN-3 warning comments inline in both files. Annotated `bkit-tokens.ts` `resolvePnpmVersion` (kept for interface stability; retired in v0.2 per pending entry — `{{PNPM_VERSION}}` token is now dead code). Two regex-based regression guards added to `bkit-modules.integration.test.ts` (lines 534–557) asserting neither ci.yml sets `with.version:` for `pnpm/action-setup@v4`. Pre-existing `toContain("10")` assertion updated (broken by template token removal). 175 tests pass; typecheck + format:check + slop-scan + lint:prose green. No version bump (still v0.1.2).
- **Related:** BAR-130, KN-3 (single-SoT rule), run 25354307730, `docs/pending.md` v0.2 `{{PNPM_VERSION}}` retire entry, `.github/workflows/ci.yml`, `.agents/templates/.github/workflows/ci.yml`, `.agents/scripts/bkit-tokens.ts`, `.agents/scripts/bkit-modules.integration.test.ts`.
